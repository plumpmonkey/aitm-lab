FIDO2/WebAuthn Security Key Registration

Extension Task: This feature is a stub for the optional extension task. Students attempting the FIDO2 extension should implement the WebAuthn registration and authentication flow here, demonstrating that the AitM attack fails against origin-bound credentials.

Why Security Keys?

FIDO2/WebAuthn security keys bind authentication credentials to the specific origin (domain) of the identity provider. When an attacker proxies the login page through a different domain, the browser refuses to release the credential because the origin does not match. This is why FIDO2 is considered phishing-resistant, while TOTP is not.

To implement this extension, you will need to:

  1. Add the py_webauthn library to the Flask application.
  2. Implement the registration ceremony at this endpoint.
  3. Implement the authentication ceremony as an alternative to TOTP.
  4. Demonstrate that Evilginx cannot proxy the WebAuthn challenge.
